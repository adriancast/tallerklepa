# Taller Klepa

Herramientas de taller guiadas para preparar el Citroën Saxo de rally.

- **Setup de chasis** (`chasis/`): pesos por rueda, geometría y centros de balanceo, muelles y barras de torsión, estabilizadoras, amortiguadores, alineación, transferencia de carga y simulación de bache.
- **Preparación del motor TU5** (`motor-tu5/`): diagnóstico, desmontaje a bandejas por cilindro, medición, equilibrado guiado, culata, calado, compresión, montaje y rodaje. TU5J4 16v, compatible con 8v.

Publicado en: https://adriancast.github.io/tallerklepa/

Cada página es un HTML autocontenido. Los datos se guardan en el navegador de quien la usa.

> Los valores por defecto son ejemplos y estimaciones. Las tolerancias, los pares de apriete y los datos de cada pieza deben salir del manual de taller y de sus fabricantes.
